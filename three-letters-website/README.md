# Three Letters Web Application 🌊🌿🌸

A personalized, romantic 3-letter web experience handcrafted for someone special who loves sharks, whales, nature, and flower fields.

## 📁 Repository Structure
- `index.html` — The minimalist 3-letter hub landing page.
- `ocean.html` — Deep-sea journey with shark & whale parallels, depth tracker, and love notes.
- `green.html` — Peaceful garden & forest letter with leaves of gratitude.
- `flowers.html` — Blooming flower field meadow letter with romantic notes.
- `styles.css` — Handcrafted custom styling, glassmorphism, and color themes.
- `script.js` — Particle engines (bubbles, leaves, petals), soundscape, and interactivity.

## 🚀 How to Deploy on GitHub Pages
1. Create a new public repository on GitHub.
2. Upload all files from this folder directly into the root of your repository.
3. Go to Settings -> Pages.
4. Set the Source branch to main (or master) and folder to / (root).
5. Click Save. In 1-2 minutes, your site will be live!
